## Footguns learned this session (promote to CLAUDE.md if they recur)

- Codex review quota can run out mid-session; the steward skill's independent-agent coverage is the
  fallback, and it must name the delta reviewed.
- A shared `CARGO_TARGET_DIR` across server worktrees masks sources as fresh (fingerprints key on
  workspace-relative paths): `find apps crates -name '*.rs' -exec touch {} +` before a verification run.
- `pnpm --filter <pkg> exec knip` reports every test file unused; run the package's `knip` script
  (`pnpm --filter <pkg> run knip`), which passes `--directory`/`--workspace`.
- `text-wrap` does not beat a `Button`'s `whitespace-nowrap` (shorthand resets `text-wrap-mode`); use
  `whitespace-normal`.
- Maven Central answers 429 to the Gradle build; a Google mirror init script fixed it
  (`/root/.gradle/init.d/central-mirror.gradle` → `maven-central.storage-download.googleapis.com`).
- GitHub runners sat queued 10–20 minutes at times; judge only the current head's run, and a cancelled
  run's `CI Gate` reads as failure.
- Serial landing on one designated branch per repo is the throughput limit; the owner allowed pushing
  prepared stories to their own branches at wind-down (names above).
